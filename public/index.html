💬 Chat CS di WhatsApp

Bagaimana cara top up?

Pilih game → isi ID player → pilih paket → pilih metode pembayaran → bayar. Setelah membayar, tekan “Saya Sudah Membayar”; admin akan memeriksa dan menyetujui pembayaranmu.

Berapa lama batas waktu pembayaran?

Kamu punya 15 menit sejak pesanan dibuat. Lewat dari itu pesanan otomatis kedaluwarsa dan kamu perlu membuat pesanan baru.

Apa arti status pesanan?

Menunggu Pembayaran — belum dibayar. Menunggu Verifikasi — pembayaran sudah kamu konfirmasi dan sedang dicek admin. Berhasil — top up selesai. Kedaluwarsa / Dibatalkan — pesanan tidak diproses.

Pesanan bermasalah atau belum diproses?

Hubungi CS (Adit) lewat tombol Chat CS. Dari halaman Riwayat atau pembayaran, pesan akan otomatis berisi ID pesananmu.

Salah isi ID atau Zone ID, bagaimana?

Segera chat CS beserta ID pesanan sebelum pesanan diproses. Bila top up sudah masuk ke ID yang kamu isi, pesanan tidak bisa dibatalkan. Lihat Kebijakan Refund.

Dari mana saya tahu Zone ID Mobile Legends?

Buka profil di dalam game: Zone ID tampil dalam tanda kurung di samping User ID, misalnya 12345678 (1234).

Saya sudah bayar tapi pesanan kedaluwarsa?

Chat CS, sertakan ID pesanan dan bukti pembayaran. Admin akan mengecek dan membantu memprosesnya.

Bagaimana dengan produk voucher (Steam, Google Play, PlayStation)?

Isi nomor WhatsApp yang aktif saat memesan. Admin akan menghubungimu lewat nomor tersebut setelah pembayaran terverifikasi.

Bagaimana memakai kode promo?

Isi kode di kolom Kode Promo pada halaman checkout lalu tekan Pakai. Satu kode hanya bisa dipakai sekali per akun, dan bisa dibatasi kuota atau masa berlakunya.

Lupa password?

Di halaman masuk, tekan Lupa password? lalu minta kode reset ke admin lewat WhatsApp. Kode berlaku 30 menit.

Kenapa ada kode unik pada total?

Kode unik (Rp10–Rp99) membantu admin mencocokkan pembayaranmu dengan pesanan. Bayar sesuai total yang tertera, tepat sampai digit terakhir.

Syarat & Ketentuan

Berlaku untuk semua pesanan di DITZ MARKET.

1. Umum

Dengan membuat pesanan, kamu menyatakan telah membaca dan menyetujui ketentuan ini. Untuk memesan, kamu perlu membuat akun dan bertanggung jawab menjaga kerahasiaan password.

2. Ketepatan data akun

Kamu bertanggung jawab atas kebenaran ID Player, Zone ID, Riot ID, username, email, atau nomor WhatsApp yang diisi. Top up yang sudah berhasil masuk ke ID yang kamu tulis tidak dapat dibatalkan.

3. Harga dan pembayaran

  • Total pembayaran = harga paket + biaya layanan + kode unik.
  • Pembayaran lewat QRIS, DANA, atau GoPay harus sesuai total, tepat sampai digit terakhir.
  • Batas waktu pembayaran 15 menit sejak pesanan dibuat. Setelah itu pesanan kedaluwarsa dan kamu perlu membuat pesanan baru.
  • Harga yang berlaku adalah harga saat pesanan dibuat. Harga dan ketersediaan produk dapat berubah sewaktu-waktu.

4. Verifikasi dan proses pesanan

Setelah kamu menekan “Saya Sudah Membayar”, admin memeriksa pembayaran secara manual, lalu memproses pesanan. Lama proses dapat berbeda-beda. Tekan tombol konfirmasi hanya setelah benar-benar membayar; konfirmasi palsu dapat membuat pesanan ditolak dan akun dibatasi. Semua pembayaran hanya disetujui oleh admin; tidak ada persetujuan otomatis.

5. Produk voucher

Untuk Steam Wallet, Google Play, dan PlayStation, nomor WhatsApp wajib diisi dan harus aktif agar admin dapat menghubungimu.

6. Larangan

Dilarang menggunakan layanan untuk penipuan, pembayaran dari sumber yang tidak sah, atau tindakan yang merugikan pihak lain. Kami berhak menolak pesanan atau menutup akun yang melanggar.

7. Status layanan

DITZ MARKET adalah toko top up independen dan tidak berafiliasi dengan penerbit game mana pun. Nama dan logo game adalah milik masing-masing pemiliknya.

8. Perubahan ketentuan

Ketentuan ini dapat diperbarui sewaktu-waktu. Ketentuan yang berlaku adalah versi yang tampil di halaman ini saat kamu memesan.

Kebijakan Privasi

Data apa yang kami simpan dan untuk apa.

Data yang kami kumpulkan

  • Username dan password akun. Password disimpan dalam bentuk hash, bukan teks asli.
  • ID game, nomor WhatsApp (bila diisi), dan riwayat pesanan.
  • Alamat IP, dipakai sementara untuk membatasi percobaan login atau pendaftaran yang berlebihan.

Tujuan penggunaan

Data dipakai untuk memproses dan memverifikasi pesanan, menghubungimu terkait pesanan, serta membantu penyelesaian kendala lewat CS. Admin dapat melihat data pesanan yang kamu buat.

Berbagi data

Kami tidak menjual datamu. Data tidak dibagikan ke pihak lain kecuali diperlukan untuk memproses pesanan atau diwajibkan oleh hukum.

Cookie

Kami memakai satu cookie sesi untuk menjaga kamu tetap masuk. Cookie ini tidak dipakai untuk iklan.

Permintaan hapus data

Ingin akun atau data pesananmu dihapus? Hubungi CS lewat WhatsApp dan sebutkan username akunmu.

Kebijakan Refund

Kapan pesanan bisa dibatalkan atau dananya dikembalikan.

Pesanan berhasil

Pesanan berstatus Berhasil tidak dapat dibatalkan atau di-refund, kecuali terjadi kesalahan dari pihak DITZ MARKET.

Salah isi ID atau Zone ID

Jika top up sudah masuk ke ID yang kamu isi, kami tidak dapat menarik kembali dan tidak ada refund. Jika pesanan belum diproses, segera hubungi CS agar bisa diperbaiki atau dibatalkan.

Sudah bayar tapi pesanan tidak diproses

Hubungi CS dengan ID pesanan dan bukti pembayaran. Setelah pembayaran terverifikasi, pesanan akan diproses ulang atau dananya dikembalikan.

Pesanan kedaluwarsa tapi sudah transfer

Kirim bukti pembayaran ke CS. Admin akan mengecek dan membantu memprosesnya.

Nominal transfer tidak sesuai

Jika nominal yang dibayar berbeda dari total pesanan, hubungi CS agar bisa dicocokkan. Selisih bisa menunda proses.

Belum dibayar

Pesanan berstatus Menunggu Pembayaran bisa kamu batalkan sendiri kapan saja lewat tombol Batalkan Pesanan.
